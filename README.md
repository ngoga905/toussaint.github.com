# Toussaint Turatsinze Portfolio

This project is a responsive personal portfolio website for Toussaint Turatsinze, an IT Manager based in Rwanda. It presents his professional profile, selected IT and cybersecurity projects, Microsoft Azure certification, and contact information in a clean single-page layout.

## Features

- **About me:** Introduces Toussaint, his role, location, and professional focus.
- **Projects and experience:** Highlights Microsoft 365 deployment and security hardening, as well as a whistleblowing system implementation.
- **Certification:** Displays the Microsoft Certified: Azure Fundamentals (AZ-900) certification earned in 2025.
- **Contact information:** Provides direct phone and email links.
- **Responsive design:** Adapts the layout for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 4.4.1 base styles

## How to Run This Project

The project is a static website and does not require a server or build process. Open [index.html](index.html) in a modern web browser to view it locally. Other people can access it after the project is published through a static hosting service such as GitHub Pages.

### Prerequisites

- A modern web browser such as Chrome, Firefox, Edge, or Safari
- Git, only if cloning the repository
- Optional: the VS Code Live Server extension for automatic browser refresh

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Move into the project folder:

   ```bash
   cd lab_session_portfolio
   ```

3. Open the folder in VS Code:

   ```bash
   code .
   ```

4. Open [index.html](index.html) directly in a browser, or right-click it in VS Code and select **Open with Live Server**.
